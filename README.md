# CryptoLab（仮称）

暗号を「解読する」体験を通して、情報セキュリティのしくみ（鍵・ハッシュ・計算量的安全性）を学ぶ Web 教材です。卒業研究として開発中。

- 公開ページ: https://224096-cmd.github.io/cryptolab/
- すべての計算はブラウザ内で完結します（サーバーへの送信なし・完全クライアントサイド）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 教材本体（v0.1 は配信テスト用ページ） |
| `.github/workflows/pages.yml` | push したら GitHub Pages へ自動公開する設定（GitHub Actions） |
| `.nojekyll` | GitHub Pages に変換処理をさせず、ファイルをそのまま配信させるための空ファイル |
| `.gitignore` | Git の管理対象に含めないファイルの指定 |

## 更新のながれ（メモ）

1. ファイルを編集する
2. `git add -A` → `git commit -m "..."` → `git push`
3. 約1分後に公開ページへ反映される（進行状況はリポジトリの **Actions** タブで確認）

## 開発予定のステージ

1. シーザー暗号を破る（総当たり＝ブルートフォース）
2. 換字式暗号と頻度分析
3. パスワードとハッシュ（雪崩効果・辞書攻撃）
4. ミニRSAと計算量の爆発（計算量的安全性）
