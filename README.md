# CryptoLab

暗号を「解読する」体験を通して、情報セキュリティのしくみ（鍵・ハッシュ・RSA・計算量的安全性）を学ぶ Web 教材です。
中学校技術科「D 情報の技術」および高等学校「情報Ⅰ」での利用を想定した、卒業研究として開発中のものです。

- **公開ページ**: https://224096-cmd.github.io/cryptolab/
- **完全ローカル動作**：サーバー不要・API不要・費用0円。すべての計算はブラウザ内で完結し、入力は外部に送信されません。
- スマートフォンでも動作します（一度開けばオフラインでも動きます）。

## 4つのステージ

| # | テーマ | 解読体験 | 主な学習内容 |
|---|---|---|---|
| 1 | シーザー暗号 | 総当たり（ブルートフォース） | 平文・鍵・暗号文／鍵空間 |
| 2 | 換字式暗号 | 頻度分析 | 統計による解読／かたよりの弱点 |
| 3 | ハッシュとパスワード | 辞書・総当たり攻撃 | SHA-256／雪崩効果／パスワード強度・ソルト |
| 4 | ミニRSA | 素因数分解 | 公開鍵暗号／剰余演算／計算量的安全性 |

各ステージは **①見る → ②破る → ③なぜ** の3部構成。実験結果は「実験ノート」に蓄積し、CSV / JSON / Markdown で書き出せます。

## 技術メモ

- ほぼ外部ライブラリ非依存（素の HTML / CSS / JavaScript）。QRコード生成のみ小さな MIT ライブラリ（qrcode-generator）を同梱（CDN不要・オフライン可）。
- 端末間の暗号の受け渡しは、問題をリンク／コードに符号化して共有（サーバー不要・1対多も可）。
- 画面遷移はハッシュルーティング（`#/stage1` など）。GitHub Pages でサーバー設定（rewrite）不要。
- 重い計算（パスワード総当たり・素因数分解・計算量ベンチ）は **Web Worker** で別スレッド実行し、画面を止めない。
- SHA-256 は表示用に WebCrypto、総当たり用に純JS実装（同一の結果）を使用。
- RSA の計算は BigInt。素因数分解は 2⁵³ 未満で正確・高速な Number 領域の試し割り。
